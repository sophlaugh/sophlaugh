# Contributing

Thanks for exploring my engineering and research work.

This repository is a public GitHub profile, not the source tree for Alden, Ava, or Cobeal Systems. Contributions here should improve public documentation, accessibility, links, or the profile automation.

## How to contribute

1. Review the relevant README and existing issues.
2. Open an issue describing the specific problem, expected outcome, and reproduction steps, if applicable.
3. Propose a small pull request with a concise explanation and verification notes.
4. Avoid mixing unrelated changes or introducing external services without documenting privacy and security implications.

Technical questions and respectful disagreement are welcome. Claims about software behavior should include tests, traces, citations, or a reproducible example whenever feasible.

**Do not include** customer material, private code, API keys, credentials, or unpublished research in issues, commits, or attachments.
