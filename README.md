# Dr. Sophy M. Laughing

**Applied AI Engineer · Independent Researcher · Creator of Project Alden**

I build and study language-model applications, AI agents, retrieval systems, and practical developer tools. My work draws on decades of delivering complex infrastructure and on independent research into intelligence, knowledge representation, and machine evaluation.

## Current work

- **[Project Alden](https://github.com/sophlaugh/Project-Alden)** — independent research into machine intelligence, evaluation, and reasoning architectures. The public repository currently contains project documentation.
- **Digital Soph** — a Python-based, source-grounded research assistant integrating Telegram, document retrieval, and configurable language models. Its implementation and research corpus are currently maintained privately.
- **[U.S. Presidential Elections](https://github.com/sophlaugh/US-PRESIDENTIAL-ELECTIONS)** — an Angular/TypeScript application.
- **[Allermans](https://github.com/sophlaugh/Allermans)** — exploration of privacy-preserving computation and individual data ownership.
