# Security policy

This repository is a public profile and documentation hub. Do not post vulnerabilities or credentials in public issues.

For GitHub-hosted repositories, use GitHub's private vulnerability reporting feature when enabled on the affected repository. If it is not enabled, use a private contact channel already published by the project owner. Do not disclose exploit details publicly before coordinated review.

Never place Discord webhook URLs, access tokens, model API keys, customer files, or internal repository content in the public profile. GitHub Actions integrations must use repository secrets and least-privilege permissions.
